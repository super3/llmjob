Third-party software inside the SYCL runtime files in this folder

The SYCL runtime here is the open-source release of the DPC++ compiler,
https://github.com/intel/llvm, release v7.2.0: the runtime itself (libsycl,
sycl9), the Unified Runtime adapters (ur_adapter_level_zero, both forms, and
ur_win_proxy_loader) and the Unified Memory Framework (libumf; on Windows it
is inside the adapters). All of that is under the Apache License 2.0 with LLVM
exceptions, whose text is LICENSE-DPCPP.txt.

That release builds the software below into those files. Each stays under its
own licence, which follows.

  Unified Memory Framework v1.2.0     Apache-2.0 with LLVM exceptions
      https://github.com/oneapi-src/unified-memory-framework
      (the same text as LICENSE-DPCPP.txt)
  oneAPI Level Zero v1.32.0           MIT
      https://github.com/oneapi-src/level-zero
      the part an adapter links to find the driver's loader
  hwloc                               BSD-3-Clause
      https://github.com/open-mpi/hwloc
      inside the Unified Memory Framework
  Zstandard                           BSD-3-Clause
      https://github.com/facebook/zstd
  emhash                              MIT
      https://github.com/ktprime/emhash
  xxHash                              BSD-2-Clause
      https://github.com/Cyan4973/xxHash
      in LLVM's support library

Not in this folder: the Level Zero loader (libze_loader.so.1, ze_loader.dll)
and the OpenCL loader (libOpenCL.so.1, OpenCL.dll). The runtime opens them by
name, and they come with Intel's graphics driver.

This list was made from what the files themselves hold (their symbols and
strings) and from the release's build scripts.
