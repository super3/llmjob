Running a HiveOS rig?

Paste your address and copy a ready-made flight sheet. HiveOS fills in the miner's settings from it, and the miner keeps itself up to date after that.

Or download it as a file
Paste your Pearl address first.
Then in HiveOS
  1. 1Open Flight Sheets and click Import from Clipboard. If HiveOS says reading the clipboard failed (Firefox blocks it), download the file above and click Import from File.
  2. 2HiveOS fills in the miner and marks Wallet as a required field. That's expected: a flight sheet can't carry a wallet. Pick your PRL wallet, or Add Wallet with the same address. Your address is already in the miner's settings, so it mines to that address either way. Then click Create Flight Sheet.
  3. 3Click the rocket next to it to apply it to your rigs.

Everything elseLeave blank. If HiveOS asks for a hash algorithm, use pearlhash. Extra config arguments are optional: --region de pins the pool region, --no-update keeps a rig on its version, and --mode auto also serves a local LLM.
  • Updates itself. The miner checks for a new version every 6 hours and restarts into it. If a new version doesn't hash within 10 minutes, the rig goes back to the one before.
  • Problems show in HiveOS. A wrong address, a flag the miner doesn't know, an image too old or a driver too old for RTX 50 cards appears as a message on the rig's page in HiveOS.
  • Ubuntu 20.04 or newer. It runs on HiveOS images based on Ubuntu 20.04 or later. RTX 50-series and RTX PRO Blackwell cards also need a newer driver: run nvidia-driver-update from Hive Shell.
  • Mining only. The rig mines and serves no LLM unless Extra config sets a mode. --mode auto also serves a local LLM, which downloads a 5–18 GB model once.
  • Turned-off cards. A card you turn off in HiveOS doesn't mine. HiveOS reads this when the miner starts, so restart the miner after turning a card on or off. The local LLM from --mode auto doesn't follow it.
  • Stats. HiveOS shows each card's hashrate, the shares and the uptime, as it does for any miner. The rig also shows on the network board.

The README has the details.

Questions

Is it safe to install?

The code is open source and the builds come from GitHub. Some antivirus tools flag every crypto miner, so Windows may warn you on first run.

What is Pearl, and how do I cash out?

Pearl (PRL) is the coin your GPU mines. To sell it, send it from your wallet to an exchange such as SafeTrade.

What does it cost?

The app is free and takes no dev fee.

What do I need?

Windows or Linux and an NVIDIA or AMD GPU. Large rigs can run it on HiveOS.

How do I track my earnings?

The app shows your hashrate and balance live. Every rig also appears on the Network page, ranked by hashrate.

What is the LLM reading?

Your GPU can also run AI models and serve requests on LLMJob's OpenAI-compatible network. The app's Chat and API tabs use it. Learn more.
