Guide

Run an LLM on your HiveOS rig

For LLMJob Earn on HiveOS. Last updated 13 November 2026

The LLMJob Earn miner can run a local AI model (an LLM) on your rig's GPUs while it mines. On HiveOS it is off by default, so your rig only mines until you turn it on. This page shows how to turn it on, check it is working, and use the model.

The short version

  • In your flight sheet, add --mode auto to the LLMJob Earn miner's Extra config arguments, then apply it.
  • The miner downloads a model once (about 5 GB) and runs it on each card that has room. It keeps mining.
  • A card pauses mining only while the model is answering a request, then goes back to mining.
  • Running the LLM does not add earnings yet. It is early, and it is where LLMJob is heading.

1. What it does

With --mode auto the miner starts a model server (llama.cpp's llama-server) next to the miner. The default model is Gemma 4 E4B, about 5 GB. It is downloaded the first time and kept on the rig's drive.

The miner gives each card a model only if the card has enough free memory left after mining. On a card with lots of memory it may pick a bigger model, and then switch that card between mining and answering as requests come in.

While a card's model answers a request, that card stops mining. It starts mining again 10 seconds after the last request ends. Your other cards keep mining, and the pool connection stays open. HiveOS and the network page show that card at 0 TH/s while it is paused.

The rig also answers requests from the LLMJob network, which is what "LLM co-mining" means. There are no extra earnings for this yet.

2. Turn it on

  1. Open your flight sheet with the llmjob-earn custom miner (set up as on the download page).
  2. Open the miner's settings and find Extra config arguments.
  3. Add --mode auto. If there is already something in the box, add it after a space.
  4. Save the flight sheet and apply it to the rig.

On a rig with a small CPU or little RAM (for example an Octominer), run the model on one card only. Each model server needs some CPU and memory:

--mode auto --llm-max-instances 1

3. Check it is working

Open the miner's log in HiveOS. The first start downloads the model, which can take a few minutes. When the model is up, the log says:

local LLM ready — OpenAI endpoint http://127.0.0.1:8080/v1

On the network page, your rig's cards show the model they are running next to the hashrate.

If the log says there is not enough free VRAM, that card is too full to run the model next to the miner. Mining carries on as normal on it.

4. Use the model

The model speaks the OpenAI API, so most apps that work with OpenAI can use it.

On the rig itself

The model listens on http://127.0.0.1:8080/v1. From the HiveOS shell:

curl http://127.0.0.1:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Say hello"}]}'

From another computer on your network

When the rig runs the LLM only (--mode llm), or switches a big card between mining and the model, the miner also opens port 8000 to your local network. Use http://<your rig's IP>:8000/v1 from any computer on the same network.

Port 8000 has no password. Anyone who can reach it can use the model, so keep it on your home network and don't forward it to the internet.

5. Options

All of these go in Extra config arguments, after a space:

  • --mode auto: mine and run the model.
  • --mode llm: run the model only, no mining.
  • --mode mining: mine only. This is what HiveOS does when you add no mode.
  • --llm-max-instances 1: run the model on at most this many cards. By default every card with room runs one.
  • --llm-model /path/to/model.gguf: use your own GGUF model instead of downloading the default.
  • --no-serve: don't answer requests from the LLMJob network. The model still runs for you.

6. What it needs

  • GPU memory: about 6 GB free on a card, after what mining uses. Cards with less just mine.
  • Disk: about 5 GB on the HiveOS drive for the default model. A bigger card may get a bigger model, up to about 18 GB.
  • CPU and RAM: each model server uses some. On a weak CPU, run one with --llm-max-instances 1.
  • Cards: it is tested most on NVIDIA cards. AMD and Intel cards may work but are less tested.

7. Turn it off

Remove --mode auto from Extra config arguments (or change it to --mode mining) and apply the flight sheet. The rig goes back to mining only.
