Adding a node

Nodes are added from the machine itself, not from this page.

Claiming a node requires proof that you control it — its private key never leaves the machine, so only the node itself can make the request.
Two ways to add one
DesktopOpen LLMJob Earn and choose “Connect with LLMJob”.
HeadlessRun llmjob-earn-cli connect --token <token>.

Your join token is on the dashboard, under Add node.
