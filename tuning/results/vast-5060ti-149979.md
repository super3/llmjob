## Notes

- box.sh bug (found by the 4090 agent on 150022): a settings change does not stop the old
  miner, so a switched GPU runs two miners. The pause/resume at 08:52 cleared it here. Until
  the box runs a fixed box.sh, reverting g1 to cu13 would have left the cu12 miner running
  next to the new one, which costs more than the 2.9% cu12 costs. So g1 stayed on cu12 until
  09:43. Then the main session started rebooting old-script boxes after each switch, and g1
  went back to cu13.
- On-box builds use nvcc 12.8 and load as cu12, so on this card they start about 3% behind
  the release cu13 core. A build has to beat cu13, not cu12, to be worth rolling out.
