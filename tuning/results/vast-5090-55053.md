# vast-5090-55053: RTX 5090 x4, Belgium (Vast machine 55053, host 253861), spot

Rented 11:43 UTC Oct 8. Driver 570.211.01, compute 12.0, power limit 500 W on every card
(stock 575 W), memory 13801 MHz. VRAM in use 1.84 GB while mining (Vast vmem_usage), so no
other tenant. `--mine-mem-clock` can't take effect (no permission to set clocks).

Driver 570 means the release runs its CUDA 12.8 core here ("the CUDA 13 build needs 580+"),
and a `"cuda": "13"` build can't load. So builds on this box are plain CUDA 12.8 builds,
compared like for like with the release's cu12 core.

All four cards sit at the 500 W cap (W=500/500) at 2317-2415 MHz, 57-78 C. They are
power-bound, which is the case where cutting DRAM traffic can raise the SM clock.

The build tools failed at setup ("Unable to connect to developer.download.nvidia.com:443",
though apt had reached that server a minute earlier), so no build could run at first.
box.sh retries the install when it restarts after a pause.
