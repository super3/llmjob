# vast-5060ti-48149: RTX 5060 Ti x8, Ohio (Vast machine 48149, spot)

Blackwell, compute 12.0. v0.5.12 release, one miner per GPU. g0-g5 are the control
group on the release default (the CUDA 13 core); g6 and g7 are the test GPUs.

Cores built on this box come from nvcc 12.8 and load as cu12, so a build is judged
against the CUDA 12 core as well as against the release default.
